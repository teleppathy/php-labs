# Практична робота №3. Основи ООП у PHP: класи та повторне використання коду

**Варіант 3 — Блог/CMS для статей.**

## Про проєкт

Простий вебзастосунок для відображення списку статей блогу, побудований на об'єктно-орієнтованому підході. Статті описані класами: базовий клас `Article` і похідний `FeaturedArticle` (рекомендована стаття з банером і пріоритетом). Колекцією статей керує клас-менеджер `Blog`, а допоміжні функції винесені в окрему «бібліотеку» `lib/functions.php`. На сторінці виводяться таблиця всіх статей, статті обраного автора, найновіші статті та підсумковий блок.

## Основний функціонал

- **Базовий клас `Article`:** властивості `title`, `content`, `author`, `publishedAt` (модифікатор `protected`), конструктор, геттери та метод `getInfo(): string`, що повертає короткий опис статті.
- **Успадкування:** клас `FeaturedArticle extends Article` додає приватні властивості `bannerImage` і `priority`; конструктор викликає `parent::__construct(...)`, а `getInfo()` перевизначено — усередині викликається `parent::getInfo()` і результат доповнюється пріоритетом та банером.
- **Клас-менеджер `Blog`:** зберігає масив об'єктів `Article` (базових і похідних), методи `addArticle()`, `findByAuthor()` (фільтрація через `array_filter()`), `listRecent()` (сортування через `usort()` та `array_slice()`), а також `getAll()` і `count()`.
- **Бібліотека функцій `lib/functions.php`:** `makeSlug()` — перетворює заголовок на slug з транслітерацією української; `truncateText()` — обрізає текст до заданої довжини; `formatDate()` — форматує дату у `дд.мм.рррр`.
- **Підключення файлів:** усі класи й бібліотека підключаються через `require_once` в `index.php`.
- **Вивід даних:** цикл `foreach` виводить статті в HTML-таблиці, поєднуючи PHP-код із HTML-розміткою (`<?php ... ?>` та `<?= ... ?>`); тип статті визначається через `instanceof`.
- **Безпечний вивід:** опис статті виводиться через `htmlspecialchars()`, що забезпечує базовий захист від XSS-атак.
- **Налагодження:** на час розробки ввімкнено `error_reporting(E_ALL)` та `display_errors`.
- **Оформлення:** дизайн перевикористано з практичної роботи №1 (`style.css`), додано лише стилі для мітки «Рекомендована» та допоміжних елементів.

## Структура проєкту

```
php_lab3/
├── classes/
│   ├── Article.php          # базовий клас статті
│   ├── FeaturedArticle.php  # похідний клас (extends Article)
│   └── Blog.php             # клас-менеджер колекції статей
├── lib/
│   └── functions.php        # допоміжні функції: makeSlug(), truncateText(), formatDate()
├── index.php                # підключення файлів, створення об'єктів, HTML-виведення
├── style.css                # оформлення вебсторінки
└── README.md                # звіт
```

## Як запустити локально

### Спосіб 1. Через вбудований сервер PHP

1. Розпакувати архів і відкрити папку `php_lab3` у VS Code.
2. У терміналі перейти до папки проєкту:

```
cd php_lab3
```

3. Запустити локальний сервер PHP:

```
php -S localhost:8000
```

4. Відкрити у браузері:

```
http://localhost:8000/index.php
```

### Спосіб 2. Через XAMPP (Apache)

1. Скопіювати папку проєкту в каталог `htdocs` у папці XAMPP (наприклад, `<шлях до XAMPP>\htdocs\php_lab3`).
2. Запустити `xampp-control.exe` і натиснути **Start** навпроти модуля **Apache**.
3. Відкрити у браузері:

```
http://localhost/php_lab3/
```
