# Практична робота №5. Взаємодія фронтенду та бекенду: AJAX, обмін даними JSON

**Варіант 3 — Блог/CMS для статей.**

## Про проєкт

Вебзастосунок для перегляду та публікації статей блогу, у якому сторінка не перезавантажується: JavaScript за допомогою `fetch()` звертається до власних PHP-ендпоінтів, які повертають дані у форматі JSON, і оновлює DOM. Дані зберігаються в базі `practicum4` (таблиця `articles` з практичної роботи №4). 

## Основний функціонал

- **Ендпоінт списку:** `api_list.php` виконує `SELECT` через підготовлений запит і повертає JSON-масив статей (`id`, `title`, `content`, `author`, `published_at`) із заголовком `Content-Type: application/json`; необов'язковий параметр `?q=` фільтрує статті за заголовком (`LIKE`).
- **Завантаження через AJAX:** при відкритті сторінки `script.js` викликає `fetch('api_list.php')` і будує таблицю в контейнері `#results`; у `index.html` немає жодного PHP-виводу таблиці.
- **Живий пошук:** на подію `input` поля пошуку виконується `fetch('api_list.php?q=' + encodeURIComponent(...))` (із затримкою 250 мс), список перемальовується без перезавантаження; застарілі відповіді ігноруються лічильником запитів.
- **Ендпоінт додавання:** `api_add.php` приймає POST (JSON-тіло через `php://input` або `$_POST`), перевіряє дані, виконує `INSERT` через підготовлений запит і повертає доданий запис із кодом `201`; при помилках повертає `405`, `422` або `500` з повідомленням `{"error": "..."}`.
- **Додавання без перезавантаження:** форма обробляється через `event.preventDefault()` і `fetch('api_add.php', {method: 'POST', ...})`; опублікована стаття з'являється у **верхній частині списку** з підсвічуванням, а лічильник «Знайдено» оновлюється.
- **Обробка помилок:** перевіряється `response.ok`, мережеві помилки перехоплюються через `try/catch` (`TypeError`); повідомлення виводяться на сторінці — в таблиці результатів (помилки списку) і над формою (помилки додавання), а не лише в консолі.
- **Безпечний вивід:** дані перед вставкою в `innerHTML` екранує функція `escapeHtml()` (захист від XSS); SQL-запити — лише підготовлені (захист від SQL-ін'єкцій).
- **Налагодження:** помилки сервера повертаються як JSON із відповідним HTTP-кодом, їх видно у вкладці Network.

## Структура проєкту

```
practicum05/
├── classes/
│   └── ArticleRepository.php  # запити до таблиці articles (пошук, INSERT) через PDO
├── lib/
│   └── functions.php          # допоміжні функції (isValidDate() та ін.)
├── api_list.php               # GET: JSON-список статей (+ ?q= пошук)
├── api_add.php                # POST: додавання статті, відповідь 201 + JSON
├── db.php                     # підключення до БД (PDO)
├── schema.sql                 # створення БД practicum4, таблиці articles і тестових даних
├── index.html                 # сторінка: поле пошуку, контейнер результатів, форма
├── script.js                  # fetch-запити, пошук, оновлення DOM, обробка помилок
├── style.css                  # оформлення вебсторінки
└── README.md                  # звіт
```

## Підготовка бази даних

Якщо базу `practicum4` з таблицею `articles` уже створено в практичній роботі №4, цей крок можна пропустити. Інакше:

1. Запустити модуль **MySQL** (у XAMPP Control Panel — **Start** навпроти MySQL).
2. Відкрити phpMyAdmin (`http://localhost/phpmyadmin`), перейти на вкладку **Імпорт**, вибрати файл `schema.sql` і натиснути **Вперед**.
3. Переконатися, що створено базу `practicum4` з таблицею `articles`.
4. За потреби змінити ім'я користувача й пароль у файлі `db.php` (за замовчуванням `root` без пароля).

## Як запустити локально

### Через XAMPP (Apache)

1. Скопіювати папку проєкту в каталог `htdocs` у папці XAMPP (наприклад, `<шлях до XAMPP>\htdocs\practicum05`).
2. Запустити `xampp-control.exe` і натиснути **Start** навпроти модулів **Apache** та **MySQL**.
3. За потреби імпортувати `schema.sql` через phpMyAdmin (див. розділ «Підготовка бази даних»).
4. Відкрити у браузері:

```
http://localhost/php_lab5/
```

## Перевірка в інструментах розробника

1. Відкрити DevTools (клавіша `F12`) → вкладка **Network** → фільтр **Fetch/XHR**.
2. Оновити сторінку: з'явиться запит `api_list.php` зі статусом `200` і JSON-відповіддю (вкладка Response).
3. Почати вводити текст у поле пошуку: на кожну зміну з'являється запит `api_list.php?q=...`, а сторінка не перезавантажується.
4. Додати статтю: у Network з'являється `api_add.php` (метод `POST`, статус `201`), у вкладці **Elements** новий рядок `<tr>` з'являється у `<tbody id="results">` без повторного завантаження документа.
5. Перевірити обробку помилок: зупинити MySQL і оновити сторінку або надіслати форму — у таблиці/над формою з'явиться повідомлення про помилку.
