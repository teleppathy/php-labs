# Практична робота №1. PHP-структури та вивід результатів у вебсторінку
Варіант 3 — **Блог/CMS для статей**.

## Про проєкт

Простий вебзастосунок для відображення списку статей блогу. Дані статей (заголовок, автор, дата публікації, кількість переглядів) описано масивом асоціативних масивів у PHP. Для кожної статті автоматично визначається мітка «Популярна» або «Звичайна», а на сторінці виводяться таблиця статей і підсумковий блок із сумарною кількістю переглядів.

## Основний функціонал

- **Опис даних:** статті зберігаються в масиві `$articles` з полями `title`, `author`, `publishedAt`, `views`.
- **Форматування запису:** типізована функція `formatArticle(array $article): string` формує короткий опис статті (назва, автор, дата у форматі `дд.мм.рррр`).
- **Умовна логіка:** функція `getLabel()` за допомогою `if/else` повертає мітку «Популярна», якщо `views > 100`, інакше — «Звичайна».
- **Вивід даних:** цикл `foreach` виводить усі статті в HTML-таблицю, поєднуючи PHP-код з HTML-розміткою (`<?php ... ?>` та `<?= ... ?>`).
- **Агрегатний показник:** сумарна кількість переглядів обчислюється через `array_sum(array_column(...))`; додатково підраховано кількість статей і кількість популярних статей (`count()`, `array_filter()`).
- **Безпечний вивід:** опис статті виводиться через `htmlspecialchars()`, що забезпечує базовий захист від XSS-атак.
- **Налагодження:** на час розробки ввімкнено `error_reporting(E_ALL)` та `display_errors`.

## Як запустити локально

### Спосіб 1. Через вбудований сервер PHP

1. Клонувати репозиторій і відкрити його папку у VS Code.
2. У терміналі перейти до папки проєкту.
3. Запустити локальний сервер PHP:

```bash
php -S localhost:8000
```

4. Відкрити у браузері:

```text
http://localhost:8000/index.php
```


### Спосіб 2. Через XAMPP (Apache)

1. Скопіювати папку проєкту в каталог `htdocs` у папці XAMPP (наприклад, `<шлях до XAMPP>\htdocs\php_lab1`).
2. Запустити `xampp-control.exe` і натиснути **Start** навпроти модуля **Apache**.
3. Відкрити у браузері:

```text
http://localhost/php_lab1/
```
