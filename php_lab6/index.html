Блог / CMS: власний API

Ця сторінка - простий клієнт для перевірки API (api.php). Усі дані надходять і надсилаються через fetch; результат кожного запиту (код статусу й JSON) видно в блоці «Відповідь API» внизу.

Маршрути API

Метод Запит Опис Коди
GET api.php?resource=articles Список статей 200
GET api.php?resource=articles&id=N Одна стаття 200, 400, 404
POST api.php?resource=articles Створення статті 201, 400
POST api.php?resource=articles&action=publish&id=N Опублікувати статтю (published_at = NOW()) 200, 400, 404
