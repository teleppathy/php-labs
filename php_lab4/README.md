# Практична робота №4. Взаємодія вебзастосунку з базою даних (PDO/MySQL)

**Варіант 3 — Блог/CMS для статей.**

## Про проєкт

Вебзастосунок для керування статтями блогу, який зберігає дані в базі MySQL/MariaDB і працює з нею через розширення PDO. Реалізовано повний набір CRUD-операцій: перегляд списку статей, додавання, редагування та видалення. Усі запити зі значеннями користувача виконуються через підготовлені запити (prepared statements), що захищає від SQL-ін'єкцій. Дизайн перевикористано з попередніх практичних робіт (`style.css`).

## Основний функціонал

- **База даних:** таблиця `articles` зі стовпцями `id`, `title`, `content`, `author`, `published_at` (первинний ключ `id INT AUTO_INCREMENT PRIMARY KEY`). Скрипт створення бази й таблиці з тестовими даними — `schema.sql`.
- **Підключення:** файл `db.php` створює і повертає об'єкт `PDO` з DSN, користувачем та паролем, а також опціями `ERRMODE_EXCEPTION` і `FETCH_ASSOC`; підключається через `require_once`.
- **SELECT:** `index.php` виконує `SELECT * FROM articles` і виводить результат у HTML-таблицю через `fetchAll()` та `foreach`.
- **Вибірка за варіантом:** `findByAuthor($author)` — `SELECT ... WHERE author = :author` (фільтр за автором у випадаючому списку); `listRecent($limit)` — `SELECT ... ORDER BY published_at DESC LIMIT :limit` (блок «Останні статті»; `:limit` передається через `bindValue(..., PDO::PARAM_INT)`).
- **INSERT:** форма на `index.php` надсилає дані в `add.php`, який виконує `addArticle()` через підготовлений запит і робить `header('Location: index.php')`; ідентифікатор нового запису повертається через `lastInsertId()`.
- **UPDATE:** посилання «Редагувати» веде на `edit.php?id=...`, де форма заповнена поточними значеннями (`SELECT ... WHERE id = :id`); після відправлення виконується `updateArticle()` з умовою `WHERE id = :id`, кількість змінених рядків повертає `rowCount()`.
- **DELETE:** кнопка «Видалити» відправляє POST-запит у `delete.php`, який виконує `deleteArticle()` (`DELETE ... WHERE id = :id`); перед видаленням запитується підтвердження через `confirm()` у JavaScript.
- **Клас-репозиторій:** уся робота з таблицею інкапсульована в класі `ArticleRepository` (`classes/ArticleRepository.php`), що продовжує ООП-підхід практичної роботи №3.
- **Валідація:** порожні поля та некоректна дата відхиляються, після операцій користувач бачить повідомлення про результат.
- **Безпечний вивід:** усі дані виводяться через функцію `e()` (обгортка над `htmlspecialchars()`), що забезпечує захист від XSS-атак.
- **Налагодження:** на час розробки ввімкнено `error_reporting(E_ALL)` та `display_errors`.

## Структура проєкту

```
php_lab4/
├── classes/
│   └── ArticleRepository.php  # робота з таблицею articles (CRUD через PDO)
├── lib/
│   └── functions.php          # допоміжні функції: e(), formatDate(), truncateText(), isValidDate()
├── db.php                     # підключення до БД (PDO)
├── schema.sql                 # створення БД practicum4, таблиці articles і тестових даних
├── index.php                  # SELECT: список статей, фільтр, форма додавання
├── add.php                    # INSERT: обробка форми додавання
├── edit.php                   # UPDATE: форма редагування й збереження змін
├── delete.php                 # DELETE: видалення статті
├── style.css                  # оформлення вебсторінки
└── README.md                  # звіт
```

## Підготовка бази даних

1. Запустити модуль **MySQL** (наприклад, у XAMPP Control Panel натиснути **Start** навпроти MySQL).
2. Відкрити phpMyAdmin (`http://localhost/phpmyadmin`), перейти на вкладку **Імпорт**, вибрати файл `schema.sql` і натиснути **Вперед**.
3. Переконатися, що створено базу `practicum4` з таблицею `articles` і шістьма тестовими записами.
4. За потреби змінити ім'я користувача й пароль у файлі `db.php` (за замовчуванням `root` без пароля).

## Як запустити локально

### Через XAMPP (Apache)

1. Скопіювати папку проєкту в каталог `htdocs` у папці XAMPP (наприклад, `<шлях до XAMPP>\htdocs\php_lab4`).
2. Запустити `xampp-control.exe` і натиснути **Start** навпроти модулів **Apache** та **MySQL**.
3. Імпортувати `schema.sql` через phpMyAdmin (див. розділ «Підготовка бази даних»).
4. Відкрити у браузері:

```
http://localhost/php_lab4/
```

## Перевірка захисту від SQL-ін'єкцій

У поля форми додавання (наприклад, «Автор» або «Заголовок») можна ввести одинарну лапку `'` або рядок `' OR '1'='1`. Підготовлені запити передають значення в СУБД окремо від тексту SQL, тому такий ввід зберігається як звичайний текст і не змінює структуру запиту та не викликає помилок.
