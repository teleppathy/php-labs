# Практична робота №2: Блог/CMS для статей

## Про проєкт

Було розроблено простий вебзастосунок для створення статей у блозі. Користувач може ввести заголовок, текст статті та теги. Дані обробляються за допомогою PHP, а чернетка автоматично зберігається у `localStorage`.

## Основний функціонал

- **Створення статті:** користувач вводить заголовок, текст статті та теги через HTML-форму.
- **Валідація даних:** введені дані перевіряються на стороні браузера за допомогою HTML5 і JavaScript, а також повторно на сервері за допомогою PHP.
- **Обробка помилок:** якщо дані введені неправильно, користувач отримує повідомлення про помилку, а вже введені значення зберігаються у формі.
- **Збереження чернетки:** введені дані автоматично зберігаються у `localStorage`, тому їх можна відновити після перезавантаження сторінки.
- **Надсилання статті:** після успішної перевірки на сторінці відображаються прийняті дані та повідомлення про успішне надсилання.
- **Безпечний вивід:** введені користувачем дані виводяться через `htmlspecialchars()`, що забезпечує базовий захист від XSS-атак.

## Правила валідації

| Поле | Правило |
|------|---------|
| `title` | обов'язкове, від 5 до 100 символів |
| `content` | обов'язкове, не менше 20 символів |
| `tags` | необов'язкове, перелік через кому |

## Структура проєкту

`form.php` містить PHP-обробник, HTML-форму та JavaScript-код.

`style.css` відповідає за оформлення вебсторінки.

## Як запустити локально

### Спосіб 1.

1. Відкрити папку проєкту у VS Code.
2. У терміналі перейти до папки `php2`.
3. Запустити локальний сервер PHP:

```bash
php -S localhost:8000
```

4. Відкрити у браузері:

```
http://localhost:8000/form.php
```

### Спосіб 2. Через XAMPP (Apache)

1. Скопіювати папку проєкту в каталог `htdocs` у папці XAMPP (наприклад, `<шлях до XAMPP>\htdocs\php_lab2`).
2. Запустити `xampp-control.exe` і натиснути **Start** навпроти модуля **Apache**.
3. Відкрити у браузері:

```text
http://localhost/php_lab2/form.php
```

Після цього відкриється форма створення нової статті.

## Приклад статті для перевірки

**Заголовок:** Що таке суперглобальні масиви $_GET і $_POST у PHP

**Текст:**

```
Суперглобальні масиви $_GET і $_POST дозволяють отримати дані, які користувач надіслав через HTML-форму. Масив $_GET містить параметри з адресного рядка, тому його не варто використовувати для чутливих даних. Масив $_POST передає значення в тілі запиту. У будь-якому разі дані потрібно перевіряти на сервері та виводити через htmlspecialchars().
```

**Теги:** `php, форми, валідація, $_POST`

## Сценарії перевірки

1. **Коректні дані** — відображається підтвердження з прийнятими даними, чернетка видаляється з `localStorage`.
2. **Порожнє поле** — JavaScript показує повідомлення без перезавантаження сторінки.
3. **Заголовок коротший за 5 символів** — помилка валідації.
4. **Текст коротший за 20 символів** — помилка валідації.
5. **Серверна валідація** — при вимкненому JavaScript (або запиті через `curl`) форма повторно виводиться з повідомленнями про помилки та введеними значеннями.
6. **localStorage** — ввести текст, перезавантажити сторінку: значення відновлюються (DevTools → Application → Local Storage, ключ `blog_article_draft`).
